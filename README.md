# Club Italia by eTeacher

Live-online Italian language school — an Italian equivalent of French Atelier by Acadomia, built for the eTeacher Group Italian faculty.

**Structure**
- 24 core HTML pages
- 11 course product pages (4 CI + 4 Parliamo + 3 Capsule)
- 11 blog post pages
- 11 downloadable syllabus PDFs (in `/pdf`)
- Biagio AI Tutor with interactive chat demo
- Advisor modal, lead form, complete site nav + footer

**Design system**
- Cormorant Garamond (serif) + Inter (sans)
- Palette: Bordeaux #3A0E12, Gold #C9A24B, Ivory #F3EDDF, Terracotta #B65538
- Structural parity with frenchatelierlive.com

**How to open locally**
Open `index.html` in any modern browser. Everything is static; no build step.
